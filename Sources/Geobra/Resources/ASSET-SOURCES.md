# Map attribution assets

`google-maps-gray.png` and `google-maps-white.png` are unmodified Google Maps attribution logos.
The app displays them only with Google map content.

Source: [Google Maps attribution assets](https://developers.google.com/static/maps/documentation/images/Google_Maps_Attribution_Assets.zip).
Usage rules: [Google Maps Tile API policies](https://developers.google.com/maps/documentation/tile/policies).

Live map images come from the selected provider.
The app displays OpenStreetMap attribution or the Google Maps logo and viewport copyright with those images.
